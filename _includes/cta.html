Liquid does not evaluate a curly-brace output tag inside an include argument - it takes the characters literally - so href="[[ '/contact/' | relative_url ]]" (with real braces) ships that whole string into the href and the button 404s. Write href="/contact/" instead. baseurl is empty on this site, so a leading-slash path is already correct. A standard link checker will not catch the broken form, because the href is not a path at all; the check that does catch it is grepping the BUILT html for a leftover opening output tag. Run it after every build on both sites.
